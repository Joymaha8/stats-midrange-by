## 🚀 Getting Started
Welcome to **stats-midrange-by**! This tool helps you compute the mid-range of numbers along selected dimensions of data. If you're looking to simplify your mathematical calculations, you're in the right place. 

## 📦 What You Need
1. **Operating System**: This application works on Windows, macOS, and Linux. 
2. **Requirements**: Ensure your system meets these requirements:
   - At least 2GB of RAM.
   - A modern web browser.
   - Internet connection for downloading the application.

## 📂 Features
- Calculate the mid-range efficiently, using one or more dimensions of your numerical data.
- Utilize a callback function for custom calculations.
- Supports multi-dimensional data structures, like ndarrays, to enhance flexibility.

## 💡 How It Works
To use **stats-midrange-by**, you will:
1. Provide a numerical dataset.
2. Choose the dimension(s) over which to compute the mid-range.
3. Optionally define a callback function for tailored calculations.
4. Run the application to get your results quickly.
